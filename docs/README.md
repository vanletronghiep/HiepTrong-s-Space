# Documentation for people

Outputs meant to be read by a person. Specs that agents follow live in `../md/`.

| Folder | Contents |
| --- | --- |
| `engineering/` | `PROJECT_DESCRIPTION.md`, the engineering reference and open decisions register |
| `audit/` | Architecture audit, bug inventory, technical debt, stabilization plan, `codebase-detox/` |
| `reports/` | Dated reports, `YYYY-MM-DD-topic.tex` and `.pdf` (v3.1 change report in its own folder) |
| `notes/` | Loose notes moved from the repository root; owner to sort or archive |
| `inspiration.md` | Reference sites for design inspiration |
