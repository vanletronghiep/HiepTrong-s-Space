Source scan of \file{src/}. This report covers font families and where each one is applied.
Font weights, sizes and line heights are not listed individually.

\section{Summary}

The project uses two web fonts, both loaded through \file{next/font/google} in \file{src/design/fonts.ts}.
No monospace or other font families are used in \file{src/}.

\begin{table}[h]
\centering
\small
\begin{tabular}{@{}p{2.8cm}p{3.6cm}p{3.2cm}p{4.4cm}@{}}
\toprule
Role & Font & CSS variable & Fallback stack \\
\midrule
Display (headings, wordmark) & Cormorant Garamond (normal and italic; latin and vietnamese subsets) & \file{--font-cormorant} $\rightarrow$ \file{--font-display} & Georgia, serif \\
UI and body text & Inter (latin and vietnamese subsets) & \file{--font-inter} $\rightarrow$ \file{--font-ui} & system-ui, -apple-system, Segoe UI, sans-serif \\
\bottomrule
\end{tabular}

\section{Notes and limits}

\begin{itemize}
  \item Components that set no font-family inherit Inter from \texttt{html, body}. They are not listed above.
  \item \file{src/features/blogs/writing-room.module.css:270} uses \texttt{font: inherit}, which takes the parent's font and adds no new family.
  \item Font weights (for example 400, 500, 600, 700) are set on many elements and are not catalogued here.
  \item Only \file{src/} was scanned. Files outside it, such as the archived docs under \file{md/archive/}, were not checked.
  \item Line numbers match the current working tree and may shift after edits.
\end{itemize}
